# CH02: TECH EXPLAINER — DESIGN BIBLE

## Visual Identity
- **Tone:** Clean, uncluttered technical explainer with structured breakdowns, state flows, and high-contrast metrics—zero mascot characters.
- **Colors:** Deep olive-charcoal/teal ground (`#071012` / `#0c191c`), Aqua (`#22E5F0`), Coral (`#F27B58`), Mint (`#7CE39A`), Ochre (`#EAB338`).
- **Fonts:** `Space Grotesk` + `Inter` + `JetBrains Mono` for English/code/metrics; `Hind Siliguri` + `Noto Sans Bengali` for Bangla headings, cards, and captions.
- **Role Split:** Web Gemini / Gem plans & generates visuals/prompts; user previews in `preview-kit.html` & runs `tts_cache.py`; `3.8 Flash` executes motion only via `flash-contract.md`.
